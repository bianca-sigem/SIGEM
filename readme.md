# SIGEM - Sistema de Gestión de Mantenimiento
Proyecto para IES - Trabajo Grupal

## Como instalar
1. Descargar ZIP
2. Poner en C:\xampp\htdocs\
3. Importar sigem_bd.sql en phpMyAdmin
4. Entrar a localhost/SIGEM
